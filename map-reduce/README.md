# Map Reduce example

Example of using Map reduce with pyspark.

## Setup Virtual environment

1) In the root of the proyect create the environment:
``` bash
python3 -m venv venv
```

2) Then, activate the environment in your Terminal in Ubuntu or Mac:
``` bash
source venv/bin/activate
```
In Windows' Powershell:

``` bash
.\venv\Scripts\Activate.ps1
```

3) Install the `requirements.txt` for the Kafka example:
``` bash
pip install -r map-reduce/requirements.txt
```
